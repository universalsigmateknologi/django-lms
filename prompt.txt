Saya ingin membuat sistem pembayaran manual semi-automatic TANPA payment gateway seperti Midtrans terlebih dahulu.

Buatkan sistem dan UI flow profesional dengan alur berikut:

USER FLOW:
1. User memilih course pada halaman
2. User klik tombol “Beli Sekarang
3. Sistem membuat Order otomatis dengan:
   - invoice unik
   - status = pending
4. User diarahkan ke halaman pembayaran
5. Halaman pembayaran menampilkan:
   - informasi transfer bank / e-wallet
   - total pembayaran
   - kode invoice
   - countdown expired payment
6. User mengupload bukti transfer di website
7. User mengisi:
   - nama pengirim
   - catatan opsional
8. Setelah upload berhasil:
   - status order berubah menjadi waiting_verification
9. Tampilkan tombol:
   “Konfirmasi via WhatsApp”
10. Saat tombol diklik:
   - membuka WhatsApp admin
   - dengan pesan otomatis berisi:
     - invoice
     - nama user
     - nama course
12. Admin dapat:
   - melihat bukti transfer
   - mengubah status payment ke paid
   - cancelled payment
13. Jika paid:
   - status menjadi paid
   - enrollment otomatis dibuat
   - user mendapatkan akses course
14. Jika reject:
   - status menjadi rejected

Saya ingin sistem dibuat CLEAN ARCHITECTURE dan scalable agar nanti mudah diintegrasikan dengan Midtrans atau payment gateway lain.
