Hello World — Program Pertamamu

Pelajari cara menulis program Python pertamamu menggunakan fungsi print() dan memahami cara menjalankannya.

4:20

Pendahuluan

Dalam dunia pemrograman, tradisi "Hello World" telah ada sejak tahun 1970-an. Program ini menjadi langkah pertama bagi hampir semua developer untuk memastikan bahwa lingkungan pengembangan mereka berfungsi dengan baik. Meskipun terlihat sederhana, program ini mengajarkan konsep fundamental tentang bagaimana Python mengeksekusi perintah.

Fungsi print()

Fungsi print() adalah fungsi bawaan Python yang digunakan untuk menampilkan output ke layar. Berikut adalah cara penulisannya:

hello.py 
# Program Hello World pertama
  print("Hello, World!")
  print("Selamat belajar Python!")
Output 
Hello, World!
  Selamat belajar Python!

Memahami Kodenya

Mari kita bedah baris kodenya:

1

Komentar

Baris yang diawali tanda # adalah komentar. Komentar tidak dieksekusi oleh Python dan berfungsi sebagai catatan untuk pembaca kode.

2

Fungsi print()

print() adalah fungsi bawaan. Kata "fungsi" berarti ia melakukan tugas tertentu — dalam hal ini, menampilkan teks ke layar.

3

String

Teks di dalam tanda kutip ganda "..." disebut string. Python juga menerima tanda kutip tunggal '...'.

Beberapa Variasi

Kamu juga bisa menggunakan print() dengan berbagai cara:

contoh.py 
# Menampilkan angka
  print(2025)

  # Menggabungkan string dengan koma
  print("Nama saya", "Rizky")

  # Menggunakan f-string (Python 3.6+)
  nama = "Rizky"
  print(f"Halo, {nama}!")

Tips

Di Python, setiap pernyataan (statement) ditulis dalam satu baris. Tidak perlu titik koma ; di akhir baris seperti di bahasa lain.
