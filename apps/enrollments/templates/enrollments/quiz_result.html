Review Jawaban
1 Siapa pencipta bahasa pemrograman Python?
Benar
Jawabanmu: Guido van Rossum

Guido van Rossum mulai mengembangkan Python pada tahun 1989 dan merilis versi pertamanya pada 1991.

2 Python termasuk bahasa pemrograman yang bertipe…
Salah
Jawabanmu: Statically typed
Jawaban benar: Dynamically typed

Python bersifat dynamically typed — tipe data variabel ditentukan secara otomatis saat runtime, tidak perlu dideklarasikan secara eksplisit seperti pada Java atau C++.

3 Apa kepanjangan dari IDE?
Benar
Jawabanmu: Integrated Development Environment

IDE adalah perangkat lunak yang menyediakan fasilitas lengkap untuk pengembangan perangkat lunak, termasuk editor kode, debugger, dan build tools.

4 Fungsi print() digunakan untuk…
Benar
Jawabanmu: Menampilkan output ke layar

print() adalah fungsi bawaan Python yang menulis argumen ke standard output (biasanya layar/konsol).

5 Manakah yang BUKAN merupakan IDE atau text editor untuk Python?
Benar
Jawabanmu: Xcode

Xcode adalah IDE resmi dari Apple untuk pengembangan aplikasi macOS dan iOS menggunakan bahasa Swift/Objective-C, bukan untuk Python.

6 Dalam Python, setiap baris pernyataan harus diakhiri dengan titik koma ;
Benar
Jawabanmu: Salah

Benar. Python menggunakan newline (baris baru) sebagai pemisah pernyataan, bukan titik koma seperti C, Java, atau JavaScript. Titik kola bersifat opsional dan jarang digunakan.

7 Apa output dari kode berikut?
Benar
output.py 
print("Hello", "World")
Jawabanmu: Hello World

Saat menggunakan koma di dalam print(), Python secara otomatis menambahkan spasi sebagai separator antar argumen.

8 Apa ekstensi file yang digunakan untuk menyimpan kode Python?
Benar
Jawabanmu: .py

Ekstensi .py adalah standar resmi untuk file sumber Python dan dikenali oleh interpreter Python serta hampir semua IDE.

9 Manakah yang merupakan cara valid untuk menulis string? (Pilih semua yang benar)
Salah
Jawabanmu:
"Hello" 'Hello'
Jawaban benar:
"Hello" 'Hello' """Hello"""

Kamu tidak memilih """Hello""" (triple quotes). Triple quotes digunakan untuk string multi-baris dan juga valid untuk string satu baris. Sementara (Hello) bukan sintaks string yang valid.

10 Untuk menjalankan file Python dari terminal, perintah yang digunakan adalah…
Benar
Jawabanmu: python file.py

Perintah python file.py menjalankan interpreter Python dan mengeksekusi skrip yang ditentukan. Di beberapa sistem, perintahnya bisa berupa python3.
